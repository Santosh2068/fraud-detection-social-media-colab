# Fraud Detection in Social Media Using NLP

## Project Overview

This academic research project explores the use of Natural Language Processing (NLP) and text mining techniques to identify suspicious content on social media platforms.

The research evaluates TF-IDF text representation and unigram, bigram, and combined n-gram features using a Naive Bayes classifier.

## Research Objectives

- Explore NLP techniques for social media content analysis.
- Compare different n-gram feature extraction approaches.
- Evaluate classification performance across cyberbullying, fake review, and misinformation datasets.

## Methodology

1. Text preprocessing
2. TF-IDF feature extraction
3. Unigram, bigram, and combined n-gram experiments
4. Naive Bayes classification
5. Model evaluation using accuracy and F1-score

## Results

| Dataset | Best Feature Approach | Accuracy | F1-score |
|---|---|---:|---:|
| Cyberbullying | Unigram | 73% | 75.8% |
| Fake Reviews | Combined Unigram + Bigram | 86% | 87% |
| Misinformation | Combined Unigram + Bigram | 81% | 84% |
